## Goal

Kodun içine gömülü, davranışı belirleyen her değer tipli bir ayar hâline gelsin. Varsayılanlar
**bugünkü davranışı birebir korusun**; isteyen her şeyi değiştirebilsin.

Ayarlar, hem CLI'ın hem ileride yazılacak UI'ın (ADR-004) hem de aracın taşınacağı suite'in
bağlanacağı tek şema olur. `cli.py` bu şemanın ince bir sarmalayıcısına iner ve **mevcut CLI
kullanımı aynen korunur.**

Mimari gerekçe: ADR-003.

## Ayar Kataloğu

Tüm renkler `"#rrggbb"`. Tüm uzunluklar aksi yazmadıkça **mm**.

### `[source]` — kaynak `.ods` boşluk doldurma

`.ods`'in söylemediği şeyler için varsayılanlar. Sayfa bir değeri veriyorsa **her zaman sayfa
kazanır** (ADR-002); buradakiler yalnızca bilgi yokken devreye girer.

| Ayar | Tip | Varsayılan | Etki |
|---|---|---|---|
| `default_col_width_mm` | float | `22.58` | `.ods`'te tanımsız sütunun genişliği (Calc varsayılanı) |
| `default_row_height_mm` | float | `4.52` | Tanımsız satırın yüksekliği |
| `default_padding_mm` | float | `0.97` | `fo:padding` yoksa hücre iç boşluğu |
| `default_font_size_pt` | float | `10.0` | Font boyutu belirtilmemişse |
| `default_text_color` | renk | `#000000` | Metin rengi belirtilmemişse |
| `default_border_color` | renk | `#000000` | Kenarlık rengi belirtilmemişse |
| `borderless_width_pt` | float | `0.5` | `"solid #000"` gibi kalınlıksız kenarlığın kalınlığı. `0` yapılırsa böyle kenarlıklar çizilmez |
| `default_v_align` | `top`\|`middle`\|`bottom` | `bottom` | Dikey hizalama belirtilmemişse (Calc davranışı) |
| `align_numeric` | `left`\|`center`\|`right` | `right` | Açık hizalaması olmayan sayı/tarih/para hücresi |
| `align_boolean` | `left`\|`center`\|`right` | `center` | Açık hizalaması olmayan mantıksal hücre |
| `align_text` | `left`\|`center`\|`right` | `left` | Açık hizalaması olmayan metin hücresi |
| `stale_check_suffixes` | liste[str] | `[".xlsx", ".xls", ".xlsm"]` | `SRC_STALE` uyarısı için yanında aranan kardeş dosyalar. Boş liste kontrolü kapatır |

| Ayar | Tip | Varsayılan | Etki |
|---|---|---|---|

| `marker_char` | str | `#` | `marker` modunda kullanılan işaret |

## Ayarlanamayanlar

Bunlar bilinçli olarak sabit kalır. Tercih değil, doğruluk koşulu:

| Sabit | Neden |
|---|---|
| `PT_TO_MM = 25.4/72` | Birim tanımı |
| ODF satır/sütun tavanı (`1048576` / `16384`) | Format kısıtı |
| Kayan nokta toleransı (`1e-9`) | AC-12 (determinizm); ayarlanabilir olması platformlar arası farkı geri getirir |
| `MTEXT` kaçış kuralları (`\`, `{`, `}`, `\P`) | Format kuralı; değiştirmek bozuk dosya üretir |
| Hata kodları (`SRC_FORMAT`, …) | Kararlı arayüz; betikler bunlara göre dallanıyor |
| Kenarlık tekilleştirme / eş doğrultulu birleştirme | Mimari karar (F-001), görünüm ayarı değil |
| Kaydırmada kelimenin bölünmemesi | Karar ve gerekçesi F-001'de; ayar yapmak iki davranışı da test etme yükü getirir |
| Dolgunun `HATCH` olması, zeminin en arkada olması | ADR kararları |

Bu tablo, "her şey ayar olsun" baskısına karşı bilinçli bir sınır. Yeni bir ayar önerildiğinde
önce buraya bakılır.

## CLI

Mevcut kullanım **değişmez.** Ek olarak:

```
--set <bölüm>.<anahtar>=<değer>      (tekrarlanabilir)
```

Örnekler:

```bash
tabletodxf mahal.ods --sheet Mahal --range B2:F40 --out t.dxf --block T \
    --set layers.prefix=PROJE_TBL \
    --set background.color=#f5f5f5 \
    --set overflow.min_width_factor=0.4
```

Öncelik: `--set` > adanmış bayrak > config dosyası > yerleşik varsayılan.

Adanmış bayrakların karşılıkları:

| Bayrak | Ayar |
|---|---|
| `--scale` | `layout.scale_cm_to_units` |
| `--frame` | `layout.frame_mm` |
| `--overflow` | `overflow.mode` |
| `--text-style` | `text.style_name` |
| `--font` | `text.font_file` |
| `--layer-prefix` | `layers.prefix` |
| `--dxf-version` | `output.dxf_version` |
| `--bylayer-defaults` | `output.bylayer_defaults` |

`--config <yol>` ve `--profile <ad>` birbirini dışlar (ikisi de "hangi `Config` ile başlanacağı"
sorusunu cevaplıyor). `--profile`, `profiles_dir()` altındaki kayıtlı bir profili yükler —
aşağıdaki "Profil Yönetimi" bölümüne bakın.

## Profil Yönetimi

Ofiste birden çok tablo tipi (mahal listesi, çizim listesi, metraj) farklı ayar ister. Bunun için
adlandırılmış, kalıcı `Config` kayıtları — **profiller** — var. Karar 2026-08-13'te verildi (bkz.
Decisions Made); önceden açık soruydu.

**Konum:** `%LOCALAPPDATA%\OncuCAD\TableToDXF\profiles\<ad>.toml`. Proje klasöründen bağımsız,
kullanıcı başına, makineye özgü (roaming değil — profiller ağ senkronizasyonuyla taşınmaz).
`OncuCAD` klasör adı bilinçli: araç ileride bir suite'e taşınacak (ADR-003), o suite'in diğer
araçları da aynı kök altında kendi alt klasörünü açabilir.

**Adlandırma:** görünen ad = dosya adı (`Mahal Listesi` → `Mahal Listesi.toml`). Ayrı bir eşleme
tablosu yok; ismi değiştirilmiş ama dosyası yeniden adlandırılmamış bir profille sonuçlanabilirdi.
Türkçe karakter ve boşluk serbest; yalnızca Windows'un dosya adında izin vermediği karakterler
(`\ / : * ? " < > |`) yasak.

**API** (`tabletodxf.config`, hepsi `__init__`'ten de erişilebilir):

```python
app_data_dir() -> Path            # %LOCALAPPDATA%\OncuCAD\TableToDXF
profiles_dir() -> Path            # …\profiles
list_profiles() -> list[str]      # alfabetik değil, kod noktasına göre sıralı — bkz. aşağı
load_profile(name) -> Config
save_profile(name, config) -> Path
delete_profile(name) -> None      # yoksa sessizce geçer
rename_profile(old, new) -> Path
ensure_default_profile() -> Path  # "Varsayılan" yoksa Config() ile oluşturur, varsa dokunmaz
```

**Sıralama kod noktasına göredir, yerel/Türkçe alfabetik değil** — `locale` bağımlılığı
makineler arası tutarsız sıralamaya yol açardı; birkaç profil arasında seçim yapan bir açılır
listede fark pratikte görünmez.

**`ensure_default_profile()` neden var:** UI açılışta bunu çağırıp profil listesinin hiçbir zaman
boş olmayacağından emin olur. Zaten `Varsayılan` varsa (kullanıcı düzenlemiş olabilir) dokunmaz.

**CLI:** `--profile <ad>`, `--config <yol>`'un yerini alan bir kısayoldur; ikisi birlikte
verilemez. Profil bulunamazsa `CONFIG_INVALID` ile durur, hiçbir dosya yazılmaz.

## Kütüphane API'si

Suite'ten ve UI'dan kullanılacak yüzey (ADR-003):

```python
from tabletodxf import Config, Job, convert, load_config, save_config

config = load_config("tabletodxf.toml")        # ya da Config()
job = Job(
    source=Path("mahal.ods"),
    sheet="Mahal",
    range_text="B2:F40",
    out=Path("mahal.dxf"),
    block="MAHAL_TABLOSU",
)
result = convert(job, config)                   # Report enjekte edilebilir
print(result.out_path, result.warnings)
```

- `Config` — kalıcı ayarlar; UI'ın düzenlediği, TOML'a yazılan
- `Job` — çalıştırmaya özgü girdiler; UI'ın her seferinde doldurduğu form
- `convert()` — CLI, UI ve suite için **tek** giriş noktası
- `Result` — çıktı yolu, rapor yolu, uyarı sayısı, varlık sayıları

Ayrım ADR-003'te gerekçelendirildi: ikisinin ömrü farklı.
